# 企業氣候轉型財務決策模擬教學系統 (ABC企業個案)

> 本專案為配合商管與EMBA教學個案《企業氣候轉型中的財務迷霧：「綠色投資」與「棕色資產」的策略抉擇》所開發之**互動式財務決策與情境模擬系統**。

## 🌟 核心特色

1. **8 大情境一鍵切換**：
   - **2023 基準實際**：還原個案起始財報（營收 120 億、淨利 8.8 億、現金 8 億、長期借款 25 億）。
   - **方案甲（保守防禦）**：綠色投資 ，碳稅  億，被砍單 5%，淨利暴跌至 3.14 億。
   - **方案乙（穩健漸進）**：投資 1.2 億美元，折衷路線，淨利 6.2 億。
   - **方案丙（積極前瞻）**：投資 2.5 億美元，綠債減息 0.5%，淨利 8.88 億。
   - **情境一（碳稅風暴與棕色資產減記）**：碳稅 /噸，產線強制認列 8 億美元減損，負債比率飆破 51.5% 觸發銀行違約紅線。
   - **情境二（流動性擠壓與高利率）**：產線超支至 3.2 億美元，期末現金被抽乾至警戒線，迫借短債。
   - **情境三（綠色軍備競賽贏者）**：大客戶轉單集中，營收增至 132 億，淨利突破 10.5 億，大幅去槓桿。
   - **方案丁（全新推導：模組化輕資產 ESCO 策略）**：採用節能合約表外租賃 + 客戶研發補貼，現金維持 8.5 億，ROA/ROE 全場最高。

2. **5 組即時敏感度微調滑桿**：
   - 碳稅單價 ( ~ /噸)
   - 客戶訂單變動 (-20% ~ +15%)
   - 綠色自籌 CapEx ( ~ .5億美元)
   - 棕色資產減損提列 ( ~ )
   - 借貸融資利率調整 (-1.0% ~ +2.5%)

3. **財務三表動態聯動與預警機制**：
   - 資產負債表嚴格平衡，動態計算流動比率、負債比率、ROE、現金安全存量。
   - 自動判定銀行聯貸財務承諾（Debt Ratio < 45%）。

4. **高階主管觀點追蹤器 (C-Suite Stance Tracker)**：
   - 執行長 CEO 鍾建國 (規模與生存)
   - 財務長 CFO 林雅婷 (現金與負債安全)
   - 永續長 CSO 陳維明 (減碳與客戶合規)

5. **哈佛式個案討論與課堂教學指引**：
   - 四大討論題卡與教師提示
   - 做與不做的代價（NPV 傳統專案法 4.77 年 vs. 戰略機會成本法 0.58 年對比）
   - 90 分鐘課堂兵棋推演（War Game）指南
